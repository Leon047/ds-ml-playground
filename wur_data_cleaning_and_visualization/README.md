# 📊 World University Ranking Analysis

This repository contains a Jupyter Notebook for analyzing global university ranking data. The project includes data cleaning, visualization, and correlation analysis between various academic performance indicators.

## 🔍 Analysis Overview

- 📥 Data loading and initial exploration
- 🧹 Missing values and outlier handling
- 📈 Distribution visualization of key metrics
- 📊 Correlation analysis between indicators:
- 🧠 Insights into the relationship between academic activity and rankings

## 🧰 Libraries Used

- `pandas`
- `matplotlib`
- `seaborn`
- `numpy`

## 📁 Repository Contents

- [Main notebook with code and visualizations](wur_data_analysis.ipynb)
- [data.csv](https://www.kaggle.com/datasets/mylesoneill/world-university-rankings/data)
